Football Match Data Scraper & ETL

Python | Beautiful Soup | Pandas | Web Scraping

This project is an automated web scraping and transformation pipeline designed to retrieve and process football match statistics. The goal was to build a reliable mechanism to extract unstructured web data and transform it into a clean, queryable format.

Architecture & Implementation

  • Extraction: Built a custom web scraper using Python and Beautiful Soup to navigate and extract match data dynamically.
  • Transformation: Utilized Pandas to handle structural inconsistencies, clean missing data points, and normalize team and player metrics.
  • Load: Exported the refined records into a clean, standardized CSV format, ready for downstream analysis or visualization tools.

The pipeline demonstrated the ability to handle messy HTML structures and turn them into actionable data sets with minimal manual intervention.

Python | Pandas | API Integration | Matplotlib

Databricks Spark ETL Pipeline

Python | Apache Spark | Databricks | SQL

An end-to-end data warehouse extraction and processing pipeline built entirely on the Databricks platform, showcasing big data scaling capabilities using PySpark.

Key Engineering Decisions

  • Distributed Processing: Used Apache Spark to scale big data transformations across multiple worker nodes, drastically reducing processing time compared to single-node pandas.
  • Schema Management: Handled complex structural schema overrides and enforced data quality checks before the write phase.
  • Cloud Integration: Exported the final processed data sets securely into cloud SQL nodes for reporting integration.

This implementation proves a strong grasp of distributed computing principles and the modern Databricks lakehouse architecture.

Fruit Classifier | Transfer Learning
